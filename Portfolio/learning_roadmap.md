# Personalised Developer Learning Roadmap

## Semester 1 (Current): Foundations & Developer Ecosystem
* **Skills Learned:** Linux command-line navigation, file permissions, binary arithmetic, Bash shell scripting, version control with Git/GitHub, and consuming REST APIs with `curl` and `jq`.
* **Tools Used:** Ubuntu Linux Terminal, Bash, Git, GitHub, VS Code, `curl`, `jq`.
* **Capstone Milestone:** Built and documented the end-to-end **DeveloperPortfolio** repository, automating system audits and directory backups while deploying a live portfolio via GitHub Pages.

## Semester 2: Core Computer Science & Web Foundations
* **Data Structures & Algorithms:** Arrays, linked lists, stacks, queues, trees, and time/space complexity analysis in Python and C++.
* **Databases:** Relational database design, normalization, and writing SQL queries (PostgreSQL / MySQL).
* **Web Basics:** Semantic HTML5, responsive CSS3 (Flexbox/Grid), and DOM manipulation with JavaScript.

## Semester 3 Onwards: Specialisation Track (Full-Stack Development)
* **Backend Engineering:** Building RESTful APIs using Python (FastAPI/Django) or Node.js (Express), authentication (JWT/OAuth), and database integration.
* **Frontend Frameworks:** Component-based UI development with React and state management.
* **Deployment & Cloud:** Containerizing applications with Docker, setting up CI/CD workflows via GitHub Actions, and deploying on cloud platforms.

## Target Certification (Before End of Semester 2)
* **Certification:** *CS50's Introduction to Computer Science (HarvardX)* or *AWS Certified Cloud Practitioner* — to validate foundational problem-solving, SQL/web skills, and cloud deployment readiness.
